## Context

GG-0003, GG-0005, and GG-0007 were observed on deployed development (web 0.6.x), while the Playwright suite runs on a local stack with the Auth emulator.

## Alternatives

1. Manual check plus Playwright assertions where criteria are automatable
2. Verification on the local E2E stack only

## Decision

Acceptance evidence is a manual browser check on deployed development, recorded as a dated Observations row with the web version in each issue. No Playwright assertions are added for these issues.

## Reason

This is the same environment in which the defects were observed, it fits the existing issue template, and it does not grow scope.

## Consequences

The evidence is a single point in time and does not protect against regressions of these issues.
