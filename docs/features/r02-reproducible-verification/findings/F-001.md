# F-001 - Existing core form defaults and browser expectations drifted

## Evidence

The complete local Playwright run initially stopped before meaningful route
audits: closed disclosures hid forms, the observation note editor required an
explicit action, and required button-driven plant/task values were removed by
React Hook Form's `shouldUnregister` behavior. Named creation commands then
failed schema validation without submitting a request. Targeted creation tests
reproduced the missing submission and passed after registration was retained.

The old Today selectors counted unrelated automatic-check list items. Garden
navigation has two independently current navigation contexts, and the mobile
shell now uses a horizontal bottom rail. Focus styling includes compound fields
with a containing-row ring or a changed border. Closed native details can retain
descendant geometry even when their controls cannot receive focus.

The existing 44px browser check also found 32px mobile application links and
28px garden-name suggestion buttons. Generated Playwright trace resources were
incorrectly included in the human-authored source-size scan after a failed run.

## Resolution

Register required button-driven plant/task fields as persistent hidden inputs;
omit an absent task time window instead of sending an empty object. Keep the
same named creation flows and real persistence assertions. Update setup and
existing audit expectations to the current disclosures, scoped navigation and
bottom rail. Validate direct or containing-row focus changes on controls that
can actually receive focus, including CSS transition frames. Restore the stated
44px minimum for the two undersized control groups. Exclude generated browser
reports/results from the source-size scan.

These repairs are needed for REQ-001's complete reproducible browser gate. They
do not add issue-specific GG-0003/0005/0007 assertions or repair the failures
recorded in their manual deployed checks (DEC-003). No new product answer or
change to an accepted decision was required.
