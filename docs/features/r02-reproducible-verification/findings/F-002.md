# F-002 - Existing browser acceptance detects excluded GG-0005 failure

## Evidence

Local complete run on 2026-10-04: 52 passed, one failed. The existing
`responsive.spec.ts` phone-canvas test expects one visible tabpanel and receives
two. The geometry, toolbar, zoom, explicit tabs, and all named core journeys pass.
This is consistent with the manual deployed GG-0005 Backdrop leakage observation.

The cause is `.panelComfort { display: flex; }` in
`map-inspector-drawer.module.css`: author CSS overrides the user-agent hidden
rule for the Backdrop tabpanel. The component already sets `hidden` correctly
and deliberately keeps all panels mounted to preserve in-flight uploads.
A proposed `.panel[hidden] { display: none; }` rule would restore visibility
without changing mounting or adding a new GG-specific browser assertion. It has
not been applied while Q-004 awaits a response.

## Resolution

Pending Q-004. Keep the assertion and the failing evidence. Do not repair the
GG-0005 failure under the existing DEC-003 exclusion without a recorded exception.
